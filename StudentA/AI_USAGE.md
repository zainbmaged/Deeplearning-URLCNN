# AI Usage Log — Student A

This file documents how AI tools were used during the Student A data preparation work.

## Tools Used

- ChatGPT
- Claude

## How AI Tools Were Used

AI tools were used as support tools during the development process.

They helped with:
- brainstorming dataset choices,
- clarifying project requirements,
- reviewing notebook structure,
- debugging Python code,
- improving markdown readability,
- checking for possible data leakage issues,
- reviewing feature extraction logic,
- reviewing scaling and SMOTE usage,
- suggesting validation checks,
- improving explanations for the report.

## What AI Tools Were Not Used For

AI tools were not used to:
- fabricate results,
- invent experiments that were not run,
- generate fake figures or tables,
- replace manual code execution,
- replace our understanding of the project.

All notebook cells were reviewed and executed before being included in the project repository.

## Main AI-Assisted Areas

The main AI-assisted areas were:
- dataset audit checklist,
- duplicate and conflicting-label checks,
- feature engineering review,
- scaling and leakage-prevention review,
- balanced and imbalanced test set design,
- SMOTE usage clarification,
- EDA figure planning,
- final notebook readability review.

## Final Note

The final notebook outputs are based on code executed and validated by the team. AI tools were used only as assistance for review, explanation, and debugging.
